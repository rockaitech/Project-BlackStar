# Project BlackStar

Continuous cyber risk quantification + adversarial investment optimization — **rupees, not scores.**

BlackStar turns a domain name into a defensible expected annual loss (Open FAIR · live EPSS/NVD/CISA KEV · Monte Carlo) and solves the exact **Stackelberg** control portfolio that stays optimal against an attacker who *adapts* to your defenses.

Built for the institutions the enterprise tools forgot — Indian colleges, government departments, and MSMEs with no SIEM, no EDR, and no security staff.

> Smart India Hackathon · Problem Statement 26105 · AICTE Cyber Security Cell

## This repository

The **showcase site** for Project BlackStar — a single, self-contained `index.html`:

- Problem, solution, and the three-layer architecture
- The end-to-end pipeline (discover → recon → correlate → graph → quantify → optimize)
- What makes it different, how it helps each stakeholder, and the compliance mapping
- A testimonials section
- Black / white theme toggle, animated attack-graph hero, scroll reveals — no build step, no dependencies
